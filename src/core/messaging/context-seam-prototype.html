Current-source evidence held constant

  • Legacy model: existing Agent, Channel, Message, and repository interfaces remain Messaging concepts.
  • Best-effort push: NotificationPort emits transport notifications; persisted messages and poll reads remain authoritative.
  • Identity gap: PID registration and connection binding prove process/session ownership, not an authenticated human or peer Principal.
  • Missing lifecycle: current code has no repository scope, ingress idempotency key, reply correlation, harness-submission state, or model-visible observation state.
  • Wrapper authority: the deterministic wrapper mediates external communication; the model does not select raw transport tools.
  • Cross-process constraint: delivery cannot assume shared memory; this prototype evaluates domain ownership only, not a runtime transport.
